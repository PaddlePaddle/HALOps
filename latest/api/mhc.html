get_workspace_for_mhc¶

get_workspace_for_mhc(
max_tokens,
hidden,
group_name,
tp_rank,
tp_size,
)¶

Allocate the all-reduce workspace of fused_all_reduce_mhc.

With tp_size > 1 this is a collective call on every rank of group_name. Allocate it once before any CUDA-graph capture and reuse it for all calls.

Parameters:

  • max_tokens (int) – Largest T of a call.

  • hidden (int) – Hidden size of x.

  • group_name (str) – Name of the tensor-parallel process group; unused when tp_size is 1.

  • tp_rank (int) – Rank in that group.

  • tp_size (int) – Size of that group, at most 8.

Returns:

The workspace to pass to fused_all_reduce_mhc.

Return type:

fused_all_reduce_mhc¶

fused_all_reduce_mhc(
x,
residual,
post,
comb,
fn,
hc_scale,
hc_base,
norm_weight,
rms_eps,
hc_pre_eps,
hc_sinkhorn_eps,
hc_post_mult,
sinkhorn_repeat,
norm_eps,
workspace=None,
comb_is_logits=False,
return_logits=False,
use_pdl=True,
)¶

All-reduce + mHC post + mHC pre + RMSNorm + W8A8-MXFP8 quantization.

Fuses the end of one mHC sub-layer with the start of the next. For every token: residual_out[j] = bf16(post[j] * x + sum_i comb[i, j] * residual[i]); the mix fn @ residual_out with its RMS gives pre, post_out (sigmoid) and comb_out (Sinkhorn); layer_out = RMSNorm(bf16(sum_j pre[j] * residual_out[j])) is quantized to MXFP8. With workspace, x is first summed over the tensor-parallel ranks. All tensors must be contiguous.

Parameters:

  • x (torch.Tensor) – [T, hidden] bfloat16 layer output, this rank’s partial sum with workspace. hidden must be 4096.

  • residual (torch.Tensor) – [T, hc, hidden] bfloat16 residual streams; hc is 2 or 4.

  • post (torch.Tensor) – [T, hc] float32 post weights.

  • comb (torch.Tensor) – [T, hc, hc] float32 comb matrices, [source, dest].

  • fn (torch.Tensor) – [hc * (hc + 2), hc * hidden] float32 mix weights.

  • hc_scale (torch.Tensor) – [3] float32 scales of the pre, post and comb mixes.

  • hc_base (torch.Tensor) – [hc * (hc + 2)] float32 mix biases.

  • norm_weight (torch.Tensor) – [hidden] bfloat16 RMSNorm weight.

  • rms_eps (float) – Epsilon of the mix RMS, 1 / (sqrt(mean(z^2)) + rms_eps).

  • hc_pre_eps (float) – Added to pre.

  • hc_sinkhorn_eps (float) – Sinkhorn epsilon.

  • hc_post_mult (float) – Scale of post_out.

  • sinkhorn_repeat (int) – Sinkhorn iterations.

  • norm_eps (float) – Epsilon of the RMSNorm.

  • workspace (MhcWorkspace | None) – From get_workspace_for_mhc; None skips the all-reduce.

  • comb_is_logits (bool) – comb holds logits, normalized in the kernel.

  • return_logits (bool) – Return the comb logits as comb_out; normalize them with mhc_sinkhorn.

  • use_pdl (bool) – Enable Programmatic Dependent Launch (on by default).

Returns:

(residual_out, layer_out, post_out, comb_out, q, sf) – bfloat16 [T, hc, hidden] and [T, hidden], float32 [T, hc] and [T, hc, hc], float8_e4m3fn [T, hidden] codes and uint8 [T, hidden / 32] UE8M0 scales in row-major layout.

Return type:

Tuple[torch.Tensor, …]

mhc_sinkhorn¶

mhc_sinkhorn(logits, eps, repeat, out=None, prefetch=())¶

Sinkhorn normalization of the comb logits of fused_all_reduce_mhc.

Turns the comb_out returned with return_logits into the matrices returned without it, and prefetches prefetch into L2 meanwhile.

Parameters:

  • logits (torch.Tensor) – [T, hc, hc] float32 contiguous logits; hc is 2 or 4.

  • eps (float) – Sinkhorn epsilon (hc_sinkhorn_eps).

  • repeat (int) – Sinkhorn iterations (sinkhorn_repeat).

  • out (torch.Tensor | None) – Optional pre-allocated output shaped like logits.

  • prefetch (Sequence[torch.Tensor]) – Up to 8 CUDA tensors, each under 4 GiB.

Returns:

[T, hc, hc] float32 comb matrices (out when given).

Return type:

torch.Tensor

Example

from halops import mhc_sinkhorn

logits = torch.randn(4, 4, 4, device="cuda")
comb = mhc_sinkhorn(logits, 1e-6, 20)

megallmhc¶

megallmhc(
x,
residual,
post,
comb,
fn,
hc_scale,
hc_base,
norm_weight,
*,
rms_eps,
hc_pre_eps,
hc_sinkhorn_eps,
hc_post_mult_value,
sinkhorn_repeat,
norm_eps,
mhc_align_fleet=False,
shared=None,
use_pdl=True,
use_swizzle=False,
token_tiles=4,
)¶

Fused mHC post + pre + RMSNorm + W8A8-MXFP8 quantization for decode.

For every token: residual_out[j] = bf16(post[j] * (x + shared) + sum_i comb[i, j] * residual[i]); the mix fn @ residual_out with its RMS gives pre, post_out (sigmoid) and comb_out (sinkhorn); layer_out = RMSNorm(bf16(sum_j pre[j] * residual_out[j])) is quantized like group_wise_quant(layer_out, "w8a8-mxfp8", use_swizzle), bit for bit. Hidden size 4096 and 4 hyper-connection streams.

Parameters:

  • x (torch.Tensor) – [T, 4096] bfloat16 layer output.

  • residual (torch.Tensor) – [T, 4, 4096] bfloat16 hyper-connection streams.

  • post (torch.Tensor) – [T, 4] float32 post weights of the previous junction.

  • comb (torch.Tensor) – [T, 4, 4] float32 comb of the previous junction, [source, dest].

  • fn (torch.Tensor) – [24, 16384] float32 mix weights, used at tf32 precision.

  • hc_scale (torch.Tensor) – [3] float32 mix scales.

  • hc_base (torch.Tensor) – [24] float32 mix biases.

  • norm_weight (torch.Tensor) – [4096] bfloat16 RMSNorm weight.

  • rms_eps (float) – Epsilon of the mix RMS.

  • hc_pre_eps (float) – Added to pre.

  • hc_sinkhorn_eps (float) – Sinkhorn epsilon.

  • hc_post_mult_value (float) – Scale of post_out.

  • sinkhorn_repeat (int) – Sinkhorn iterations.

  • norm_eps (float) – Epsilon of the RMSNorm.

  • mhc_align_fleet (bool) – Use 1 / (sqrt(ms) + eps) for the mix RMS and exp2 in sinkhorn, as fleet; off by default.

  • shared (torch.Tensor | None) – Optional [T, 4096] bfloat16 term added to x.

  • use_pdl (bool) – Enable Programmatic Dependent Launch (on by default).

  • use_swizzle (bool) – Scales in the CUTLASS SfAtom layout, rows padded to a multiple of 128.

  • token_tiles (int) – Max token tiles of the first kernel’s grid; does not change the result.

Returns:

(residual_out, layer_out, post_out, comb_out, q, sf) – bfloat16 [T, 4, 4096] and [T, 4096], float32 [T, 4] and [T, 4, 4], float8_e4m3fn [T, 4096] codes and uint8 [T, 128] UE8M0 scales ([ceil(T / 128) * 128, 128] with use_swizzle).

Return type:

Tuple[torch.Tensor, …]

mhc_post_hc_mean¶

mhc_post_hc_mean(x, residual, post, comb, use_pdl=True)¶

mHC post mixing after the last layer, averaged over the hc streams.

Computes mean_j bf16(post[j] * x + sum_i comb[i, j] * residual[i]) per token in fp32, rounded to bf16. All tensors must be contiguous.

Parameters:

  • x (torch.Tensor) – [T, hidden] bfloat16 layer output.

  • residual (torch.Tensor) – [T, hc, hidden] bfloat16 residual streams; hc is 2 or 4.

  • post (torch.Tensor) – [T, hc] float32 post weights.

  • comb (torch.Tensor) – [T, hc, hc] float32 comb matrices, [source, dest].

  • use_pdl (bool) – Enable Programmatic Dependent Launch (on by default).

Returns:

[T, hidden] bfloat16 tensor.

Return type:

torch.Tensor

Example

from halops import mhc_post_hc_mean

x = torch.randn(4, 4096, dtype=torch.bfloat16, device="cuda")
residual = torch.randn(4, 4, 4096, dtype=torch.bfloat16, device="cuda")
post = torch.rand(4, 4, device="cuda")
comb = torch.rand(4, 4, 4, device="cuda")
out = mhc_post_hc_mean(x, residual, post, comb)
